## Visual and Safety Notes

The **Holographic Core** and voice-state animations are local Flutter rendering: idle, listening, thinking, and talking states are visualized without pretending that a microphone is active when it is not. The **Hacking Dashboard** is intentionally isolated and labelled **PRANK MODE — SIMULATION ONLY**. It contains local-only visual effects for entertainment and does not scan, crack passwords, access cameras, connect to targets, mine crypto, or control infrastructure.

The real assistant surfaces remain separate: unsupported or destructive terminal commands are rejected, GPS displays real readings or an unavailable state, and mesh pairing requires a valid code and target approval.

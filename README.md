## 🏛️ System Architecture & Key Modules

| Module | Component | Description |
| :--- | :--- | :--- |
| **Presentation** | **Cyberpunk UI (`main.dart`)** | Neon cyan/magenta 2080 aesthetic with dark glassmorphic cards and responsive assistant views. |
| **Security & Auth** | **AuthGate & AuthService** | Guarantees SharedPreferences persistence for Google email, secure PIN setup, recovery email, and biometric lock. |
| **AI Brain & Commands** | **Smart Chat Router** | Automatically routes conversational queries to Groq, Gemini, or custom OpenAI endpoints, while executing explicit native commands (`open youtube`) securely. |
| **Mesh & Telemetry** | **MeshBridge & SystemBridge** | Handles nearby Bluetooth discovery, internet relay pairing, GPS coordinates, battery stats, and Android package management. |
